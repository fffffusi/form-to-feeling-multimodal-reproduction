## 关键边界(必须遵守)

1. **跳过 — 这些归功能,不要在本任务抽出**:
   - "稳/稳当/很稳/挺稳/稳定/稳固" → 功能-稳定性承重
   - "用料/用料足/用料实在/板材/钢架/实木/碳纤维" → 功能-材质做工
   - "质量不错/质量很好/质量真的好/质量没问题/质量可以/质量还行" → 功能-材质做工
   - 客观使用层评价(桌面光滑/板材厚实) → 功能

2. **归本维度 — 主观视觉印象**:
   - "看着质量/感觉质量/看起来有质感/看着不廉价" → 高级-廉价(主观印象)
   - "看着高级/看着上档次" → 高级-廉价

3. **'土' 字归属**:
   - 配 颜色/配色("颜色土") → 精致美观-粗糙难看(审美难看)
   - 配 造型/设计/风格("造型土") → 时尚科技-传统老气(过时)

4. **'做工' 归属**:
   - 描述 细节/毛刺/打磨/缝隙 → 精致美观-粗糙难看
   - 描述 板材/钢架/用料 → 跳过(归功能-材质做工)

5. **'沉稳' 是本维度唯一保留的气质类词**(归厚重-轻薄)

6. **颜色/实物不符** → 精致美观-粗糙难看 polarity=-1:
   - "颜色不符 / 颜色不一致 / 色差大 / 实物颜色与图片不符 / 实物颜色不一样"
   - "实物不符 / 与图片不符"(若涉及视觉外观)
   - 注:仅 颜色/造型/外观 类不符归本维度;若指功能配置不符(如灯走线/接口缺失)归功能

## 严格规则

1. span 必须是评论原文中**连续真实出现**的字符串,不改写
2. **不抽情感词**:满意/喜欢/推荐/不错/好/差 等不抽
3. **polarity = 词本身极性**(感性规则):正向种子=+1,反向种子=-1。negated 独立标记否定,**不影响 polarity**
4. **negated**:命中词前 1-3 字内有"不/没/无/并不/未/毫无"则 true。例外不算:不错/不少/不止/不仅/不但/不光/无论/无比
5. **degree_word**(前置:命中词前 1-3 字 / 后置:命中词后 1-3 字仅限 "还行/还可以/还是可以/尚可/过得去"):
   - 强 1.0(前置): 非常/特别/超级/超/很/十分/极/极其/太/真的/格外/巨/贼/老
   - 中 0.7(前置): 比较/挺/蛮/还算/相当/颇/颇为/够
   - 弱 0.4(前置): 有点/稍微/略/有些/有一点
   - 弱 0.4(后置): 还行/还可以/还是可以/尚可/过得去
   - 例: "够大气"→degree="够"(中级);"质量还行"→degree="还行"(弱级后置)
   - 无填 ""
6. 一条评论同一维度可多次命中;同 span 只归一个最匹配维度

## 程度词歧义提醒
- "老结实/老好看" → degree_word="老" (强 1.0)
- "老气/老旧/老套" → 不是程度词,是种子词(时尚科技负向)
- "巨稳/巨厚" → degree_word="巨";"巨型/巨大" → 不抽
